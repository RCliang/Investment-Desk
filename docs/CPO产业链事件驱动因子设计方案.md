# CPO产业链事件驱动因子设计方案

以CPO(共封装光学/光模块)产业链为例,梳理数据源和一套简单的事件分类打分流程,可套用到其他产业链的事件因子设计上。

---

## 一、数据源

### 1. 官方强制披露类(最权威,噪音最小)
- **巨潮资讯网(cninfo.com.cn)**:A股法定信息披露平台,定期报告、临时公告、股东调研纪要、可转债/定增公告都在这里
- **上交所/深交所"互动易"/"上证e互动"**:投资者提问、管理层直接回复,经常能挖到产业链细节
- **中国海关总署月度进出口数据**:按HS编码查光通信器件进出口,验证海外需求是否真实放量
- **国家知识产权局专利检索**:判断技术布局节奏,更适合中长期因子而非短线事件

### 2. 产业研究/资讯类(专业、更新快)
- **DIGITIMES、TrendForce集邦咨询**:台湾产业链消息源,对光模块/半导体供应链覆盖全面
- **LightCounting、Cignal AI**:海外光通信市场研究机构,发布市场预测报告
- **C114通信网、飞象网**:国内通信产业链垂直媒体
- **半导体行业观察、芯师爷等公众号**:信息及时,但微信内容抓取受平台协议限制,建议走授权数据服务

### 3. 财经快讯/情绪类(量大、噪音大)
- 财联社电报(7×24快讯)、华尔街见闻、同花顺资讯、东方财富资讯:适合捕捉"事件是否发生"
- 雪球、股吧:适合做情绪/关注度因子,需要较强清洗降噪

### 4. 龙头公司及海外映射链
- 国内龙头:中际旭创、新易盛、天孚通信、光迅科技等的公告、调研纪要、股东大会记录
- 海外映射:英伟达、台积电、Meta、Microsoft、Google的资本开支指引和财报电话会——**SEC EDGAR**(sec.gov/edgar)可免费获取10-K/10-Q/8-K全文,权威且合规

### 5. 优先用现成接口,少自建爬虫
- **akshare、tushare**:开源Python库,已封装A股公告、新闻、行业数据接口
- 巨潮资讯网本身有公告下载接口,可直接拿结构化数据
- 预算允许可用Wind/同花顺iFind的公告全文检索+事件提醒功能

### 6. 抓取合规注意事项
- 官方公开信息(交易所公告、海关数据)合规抓取问题不大,但要控制频率、遵守robots.txt
- 付费研究报告(如LightCounting)属版权内容,不建议绕过付费墙,优先官方订阅
- 微信生态内容有平台协议限制,规模化抓取容易被限流封号

## 二、事件分类打分流程框架

### 1. 事件分类体系
按产业链环节划分,便于区分事件的性质和影响链条:

| 类别 | 举例 |
|---|---|
| 需求端-资本开支 | 英伟达/Meta/微软上调AI资本开支指引 |
| 需求端-订单 | 龙头厂商获得大厂追加订单/中标 |
| 供给端-产能 | 产能扩张落地、良率突破 |
| 供给端-送样 | 新产品送样、通过大厂认证 |
| 政策/行业 | 出口管制、行业标准发布 |
| 公司治理 | 高管变动、股权激励、并购重组 |
| 舆情/情绪 | 分析师上调评级、机构调研密集 |

### 2. 强度与情感打分(示例)

| 事件类型 | 基础权重 | 典型情感方向 | 衰减半衰期 |
|---|---|---|---|
| 需求端-资本开支 | 5 | 正面 | 60个交易日 |
| 需求端-订单 | 5 | 正面 | 30个交易日 |
| 供给端-产能 | 4 | 正面 | 45个交易日 |
| 供给端-送样 | 3 | 正面 | 20个交易日 |
| 政策/行业 | 4 | 双向(需判断) | 30个交易日 |
| 公司治理 | 2 | 中性偏双向 | 10个交易日 |
| 舆情/情绪 | 1 | 双向 | 5个交易日 |

以上权重和半衰期是经验性起点,实际使用中应结合回测调优,避免拍脑袋定死。

### 3. 时间衰减函数
用指数衰减描述事件影响力随时间递减:

```
score(t) = base_score × sentiment_sign × exp(-t / half_life)
```

- `t`:距离事件发生的交易日数
- `sentiment_sign`:+1(正面)/ -1(负面)/ 0(中性)
- `half_life`:该事件类型对应的衰减半衰期

### 4. 因子合成
- **个股层面**:对回看窗口内(如过去N个交易日)发生的所有事件,计算decayed score之和,得到该股票的事件因子值
- **ETF/行业层面**:按ETF成分股权重加权平均,得到ETF层面的事件因子值
- **与传统因子融合**:可作为独立因子按权重并入总打分,也可作为"筛选层"——只在有正面事件催化的候选中挑动量最优的标的

### 5. 处理流程(Pipeline)
1. **数据抓取**:按第一部分数据源抓取原始文本(公告、新闻、快讯)
2. **文本清洗**:去重、去噪(广告/无关内容)、按公司及产业链关键词过滤
3. **事件识别与分类**:先用关键词规则(如"资本开支""产能爬坡""送样""中标"等关键词库)初筛,有条件可叠加NLP模型/大模型做事件类型分类和情感判断
4. **强度打分**:结合事件类型基础权重,和文本中的具体数据(订单金额、产能增幅百分比)做强度修正
5. **时间衰减加权**:按事件类型对应半衰期计算当前时点的剩余影响力
6. **因子合成**:按上述方式生成个股及行业/ETF层面的事件因子值
7. **有效性检验**:用历史数据回测该因子对未来收益的预测力(如分组回测、IC分析),再决定融合权重

### 6. 注意事项
- 关键词规则起步简单但容易漏判/误判,建议先用小样本人工标注验证规则准确率
- 同一事件在不同基本面背景下影响可能相反(如"扩产"在需求旺盛期是利好,需求转弱期反而引发产能过剩担忧),情感打分不能只靠关键词简单判断
- 衰减半衰期本质也是需要回测调优的超参数,同样要警惕过拟合
- 事件因子天然噪音比价格类因子大,建议作为动量/趋势因子的辅助层,而非唯一决策依据
